# Code of Conduct

KPViz follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and focus on
the work. Harassment, personal attacks and discrimination are not tolerated
in issues, pull requests or any other project space.

To report a concern, write to the maintainer listed in
[CITATION.cff](CITATION.cff). Reports are handled confidentially.
